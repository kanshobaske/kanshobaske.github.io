SITE MANAGER

ニュース・大会予定・写真の編集

フォームに入力して項目を追加・編集・削除できます。HTMLやJavaScriptを直接書き換える必要はありません。

GitHubへ直接保存：下の設定で専用トークンを入力すると、この管理画面から変更内容を直接GitHubに保存できます。
GitHubでトークンを作成

トークンはこのページ内のメモリでのみ扱い、ブラウザ保存やサイトのファイルへの書き込みはしません。ページを再読み込みすると再入力が必要です。

必要な権限：対象リポジトリをこのサイトのリポジトリだけに限定し、Repository permissions の Contents を Read and write にしてください。有効期限は短め（例：30日）にしてください。

  1. 編集したい内容のタブを選び、フォームから追加・変更・削除します。
  2. 「データをコピー」を押し、GitHubの編集画面を開きます。
  3. 鉛筆マークから編集画面に入り、コード全体をコピーした内容に置き換えます。
  4. 「Commit changes」で保存します。公開サイトへの反映には少し時間がかかることがあります。
