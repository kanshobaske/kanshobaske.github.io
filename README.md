# 諫早商業高校 男子バスケットボール部 Webサイト

長崎県立諫早商業高等学校 男子バスケットボール部の活動情報を紹介するWebサイトです。高校の課題研究で制作・改善しています。

## 🛠 管理画面

**[ニュース・大会予定・写真を編集する（管理画面を開く）](https://kanshobaske.github.io/admin.html)**

ニュースや大会予定の追加・編集・削除はこちらから行えます。フォームで編集したあと、GitHubへ直接保存するには、管理画面でGitHubトークンを設定してください。

- **公開サイト:** https://kanshobaske.github.io/
- **GitHubリポジトリ:** https://github.com/kanshobaske/kanshobaske.github.io


## Webサイトの内容

- **HOME（index.html）**：部の紹介、新着ニュース、今後の予定、大会写真のプレビュー、アクセス
- **ニュース（news.html）**：大会の予定・結果、活動報告、部員募集などのお知らせ
- **大会予定（basketballschedule.html）**：試合・大会の予定
- **大会写真（gallery.html）**：大会や練習試合の写真
- **進路先（sinrosaki.html）**：主な進学先・就職先
- **諫早商業高校について（isahayashougyounituite.html）**：学校の紹介

## ニュース・大会予定・写真をフォームで編集する

編集フォーム： https://kanshobaske.github.io/admin.html

### 直接保存する方法
1. 管理画面を開き、「GitHubでトークンを作成」を押します。
2. GitHubで Fine-grained personal access token を作り、対象リポジトリを `kanshobaske/kanshobaske.github.io` だけに限定します。
3. Repository permissions の **Contents** を **Read and write** に設定し、期限を設定してトークンを作成します。トークンは画面に一度だけ表示されるので、管理画面のトークン欄に貼り付けます。
4. 「接続を確認」を押したあと、ニュース・大会予定・写真のフォームで編集します。
5. 対象の「GitHubに直接保存」を押すと、そのデータファイルがリポジトリに直接コミットされます。公開サイトへの反映には少し時間がかかる場合があります。

**トークンの安全管理：**トークンをチャットに送ったり、コードに貼り付けてコミットしたりしないでください。管理画面はトークンをブラウザ内に保存せず、GitHub APIへのリクエストにだけ使用します。ページを閉じる／再読み込みすると、トークンをもう一度入力する必要があります。使い終わったら「トークンを消す」を押してください。トークンの設定に詳しくない場合は、従来どおり「データをコピー」からGitHubで手動保存する方法も使えます。

大会予定は `schedule-data.js` にまとめて管理し、ホームの予定表と大会予定ページの両方で同じデータを使用します。写真ファイル自体は `img/gallery/` にアップロードしてから、管理画面の「写真」タブでファイルパスなどを登録します。


## ニュースの追加・更新方法

1. リポジトリで `news-data.js` を開き、鉛筆マーク（編集）を押します。
2. `newsData` 配列の先頭に、新しい記事を追加します。新しい記事を先頭に置くと、日付順で表示されます。
3. `date`（日付）、`category`（分類）、`title`（見出し）、`desc`（本文）を記入します。
4. **Commit changes** を押して保存します。

記入例：

```js
{
  date: "2026.10.20",
  category: "活動報告",
  title: "練習試合を行いました",
  desc: "練習試合の結果や活動の様子を紹介します。"
}
```

ニュースは `index.html` と `news.html` で同じデータを利用するため、片方だけ内容が違う問題を防げます。分類は「大会予定・結果」「活動報告」「部員募集」「お知らせ」など、記事に合うものを使います。

## 大会写真の追加方法

1. 掲載してよい写真をリポジトリ内の `img/gallery/` にアップロードします（例：`img/gallery/spring-tournament.jpg`）。
2. `gallery-data.js` を開き、`galleryData` 配列に写真の情報を追加します。
3. **Commit changes** を押して保存します。

記入例：

```js
{
  src: "img/gallery/spring-tournament.jpg",
  title: "春季大会",
  date: "2026.04.20",
  description: "大会でのプレーの様子"
}
```

`src` は実際にアップロードしたファイルのパス・名前と一致させてください。登録した写真はホームのプレビューと大会写真ページに表示されます。部員の顔が写った写真を公開するときは、学校のルールや本人・保護者の許可を確認してください。

## 大会予定の更新方法

ホームの予定表と大会予定ページは、どちらも `schedule-data.js` を使います。通常は管理画面の「大会予定」タブから更新してください。過去の予定を今後の予定として掲載しないよう、日付も確認してください。

## デザインの変更

- `style.css`：サイト全体の基本デザイン
- `news-gallery.css`：ニュース・大会写真ページの追加デザイン

元の赤・白・グレーを中心としたデザインを保つ場合は、まず現在のCSSを確認し、必要な箇所だけを変更してください。

## 変更を公開サイトへ反映する

GitHub上でファイルを編集して **Commit changes** で保存すると、GitHub Pagesが更新を開始します。公開サイトに反映されるまで少し時間がかかる場合があります。すぐに変わらないときは、数分待ってからページを再読み込みしてください。
